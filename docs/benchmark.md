# FormoraReport 批量生成性能基准

> 生成时间: 2026-10-26
> 基准脚本: `scripts/benchmark_batch.py`（100 份批量生成，仅生成环节，不含数据读取）
> 对比依据: v2.17.0 CHANGELOG 记录的优化前后数据（41.9ms → 34.4ms/份，约 -18%）

## 环境

| 项 | 值 |
|----|----|
| 操作系统 | Windows 10 (10.0.19045 / 22H2) |
| CPU | AMD Ryzen 7 1800X Eight-Core Processor |
| 架构 | AMD64 (x86_64) |
| Python | 3.14.7（项目 venv：`.venv/Scripts/python.exe`） |
| 模板 | `tests/samples/实验报告模板.docx` |
| 数据 | 100 行 × 2 列（脚本内构造，绕开 data_reader） |

## 命令

```bash
QT_QPA_PLATFORM=offscreen ./.venv/Scripts/python.exe scripts/benchmark_batch.py
```

- `QT_QPA_PLATFORM=offscreen`：无头运行，避免 Qt 平台插件错误。
- 脚本不写入真实任务历史（`record_task` 被替换为空操作），输出写入 `tests/output/bench_batch/`。

## 实测数据（5 次运行）

| 运行 | 总耗时 (ms) | 平均 (ms/份) | 成功/失败 |
|------|------------|--------------|-----------|
| 1 | 3644.1 | 36.44 | 100/0 |
| 2 | 4154.8 | 41.55 | 100/0 |
| 3 | 4011.1 | 40.11 | 100/0 |
| 4 | 3659.3 | 36.59 | 100/0 |
| 5 | 3480.5 | 34.81 | 100/0 |

- 前 3 次平均：**39.37 ms/份**
- 5 次平均：**37.90 ms/份**（波动范围 34.81 – 41.55 ms/份）

## 优化前后对比

v2.17.0 引入的批量生成性能优化（模板解析缓存，路径+mtime+size 为键，LRU 32；jinja 编译缓存 LRU 256）在变更日志中的基准结果为：

| 阶段 | 平均耗时/份 | 说明 |
|------|------------|------|
| 优化前 | 41.9 ms | v2.16.x 基线 |
| 优化后 | 34.4 ms | v2.17.0，约 -18% |

本机复测（v2.17.0 之后版本）平均 **37.90 ms/份**，最低单次 34.81 ms/份，已稳定低于优化前基线（41.9 ms/份），并与优化后目标（34.4 ms/份）处于同一水平。与 34.4 ms 的少量差距来自硬件差异（CHANGELOG 原基准在 i5-10400F 开发机上测得，本机为 Ryzen 7 1800X）。

## 结论

1. 批量生成 100 份报告在 5 次运行中全部成功（100/0），无失败。
2. 平均 **37.90 ms/份**（约 3.8 秒/100 份），性能稳定，波动约 ±3 ms。
3. v2.17.0 的缓存优化效果可复现：实测平均低于优化前 41.9 ms/份，接近优化后 34.4 ms/份。
4. 该脚本适合作为优化前后对比的固定基准工具。

## 脚本参数说明

- **无命令行参数**：`scripts/benchmark_batch.py` 不支持 argv 传参。
- 可调常量：脚本顶部 `N_ROWS = 100` —— 修改该值可改变批量份数，输出平均 = 总耗时 / N_ROWS。
- 输出目录：`build_state()` 中的 `out_dir`（默认 `tests/output/bench_batch`）。
- 模板/数据路径：`TEMPLATE` / `SAMPLES` 常量（默认 `tests/samples/实验报告模板.docx` 与 CSV）。
